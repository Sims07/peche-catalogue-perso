Connexion au dépôt GitHub

Les prises sont enregistrées directement dans un fichier de ton dépôt GitHub, via un jeton personnel que toi seul détiens. Le jeton reste uniquement dans ce navigateur : il n'est jamais écrit dans le code du site.

Crée un fine-grained personal access token limité à ce seul dépôt, avec la permission « Contents: Read and write ». Settings → Developer settings → Personal access tokens → Fine-grained tokens.
